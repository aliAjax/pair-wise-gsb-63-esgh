# 游乐设施日常检验与缺陷闭环平台

基于 Vue3、Naive UI、Pinia、Vue Router、TanStack Query、Axios、WebSocket 和 Vite 的独立前端工程。数据默认保存在 localStorage，无需后端即可演示。

## 功能

- 检验任务列表、关键词和状态/区域筛选、统计概览。
- **班组派工**：每条缺陷安排班组、处置时段（含早/中/晚班预设）和资质要求；班组主数据带资质，资质不满足直接拦截。
- **占用校验**：同一班组同一时段只能接一项，按绝对时段比较，跨交接班的重叠排工同样拦截；看板提供班组占用一览。
- **紧急顶替**：紧急/更高风险缺陷可顶替占用时段内的低风险计划；被顶缺陷保留原班次、原时段快照和全部证据，进入「待重排」泳道，重新排班后回整改流程。
- **断网离线**：班组断网完成处置或新建缺陷先暂存现场终端；回台一键同步合并——重复操作号只入一次；同一缺陷两侧同时修改（现场基线版本落后）时保留两版，裁决前阻止关闭。
- **设备放行联动**：设备仍有未关闭缺陷（含待裁决两版、异常项）时不能恢复开放；复测通过后关闭缺陷，同设备无其他未关闭缺陷时自动恢复开放。
- 缺陷处置泳道（含待重排）、风险排序、班组/时段/资质卡片。
- **修订追溯**：每次排程、顶替、回传、裁决、关闭均留一版修订（班组、时段、原因、来源），详情页和审计页可沿班组、时段和修订重新打开找到每次原因。
- JSON 记录导出、版本号和完整操作时间线。

## 启动

```bash
npm install
npm run dev
```

访问 `http://localhost:18463`。

## 演示动线

1. 看板「派工」INS-240821-01（紧急，高空飞翔）→ 选维修一组 09-30 早班 → 触发顶替 INS-240821-02（低），后者进入待重排。
2. INS-240821-05（高，需电气+高处）派给维修一组被资质拦截；INS-240821-06 排 15:00-18:00 跨班时段被维修二组早班任务拦截。
3. 详情页「断网完成处置」→ 看板「网络恢复·同步合并」；点「模拟网络重发」验证去重；先点「模拟主台同时修改」再同步可看到两版保留与关闭拦截。
4. INS-240821-03 复测通过关闭并恢复开放；同设备再建一条缺陷时放行被联动拦截。
